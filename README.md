# 🔍 Smart Multi-Object Camera Detector & Finance

Aplikasi deteksi multi-objek berbasis web bertenaga AI (**TensorFlow.js + COCO-SSD**) yang dapat mendeteksi berbagai macam barang di sekitar secara langsung menggunakan kamera HP atau laptop, serta mengkalkulasi estimasi nilai/keuangan secara otomatis.

## ✨ Fitur Utama:
- **80 Kategori Objek COCO Dataset**: Mendeteksi gadget (HP, laptop, mouse, keyboard), makanan/minuman (botol, gelas, buah, roti), peralatan dapur, tas & aksesoris, perabotan ruangan (kursi, meja, tv, sofa), dan banyak lagi.
- **Deteksi Banyak Barang Sekaligus (Multi-Object HUD)**: Dilengkapi bounding box neon berwarna khusus untuk setiap kategori dan rangkuman live counter barang di sekitar.
- **Kontrol Sensitivitas & Filter Kategori**: Slider ambang batas keyakinan (confidence threshold) dan toggle kategori objek untuk memudahkan deteksi benda di latar/jarak jauh.
- **Multi-Camera Support**: Beralih antara kamera depan dan belakang (*facingMode: environment / user*).
- **Kalkulator & Pengelola Pengeluaran**: Input otomatis barang terdeteksi dengan estimasi harga dalam Rupiah (Rp) yang dapat disesuaikan.
- **Riwayat & Salin Rekap**: Simpan riwayat ke penyimpanan lokal (`localStorage`) dan salin rekap rapi untuk dibagikan ke WhatsApp.
